# 구글 캘린더 자동완성 v2.4 변경 내역 및 테스트 가이드

## 주요 신규 기능 (v2.4)

### 1. 새 일정 등록 시 "일정 강제 새로고침" 자동 실행
- 구글 캘린더에서 일정을 저장할 때(저장 버튼 클릭, `Ctrl+S` / `Cmd+S`, 또는 제목 입력창 엔터 저장), 1.5초 후 백그라운드에서 자동으로 `forceRefresh`가 실행됩니다.
- 구글 서버에 저장된 최신 일정을 자동으로 동기화하여 다음 번 일정 작성 시 즉시 추천 목록에 반영됩니다.
- 토큰이 유효한 상태에서는 불필요한 로그인 팝업 없이 백그라운드에서 신속하게 갱신되며, 동시 중복 호출이 방지됩니다.

### 2. 자동완성 시 시간(시작/종료 시간 및 종일 여부) 자동 완성
- 자동완성 추천 목록에서 각 일정의 **⏰ 시간**(예: `⏰ 오후 2:00 ~ 오후 3:30`) 또는 **📅 종일** 여부가 표시됩니다.
- 자동완성 항목을 클릭하면:
  - **종일 일정인 경우**: "종일" 체크박스가 활성화됩니다.
  - **시간 지정 일정인 경우**: "종일" 체크박스를 해제하고, "시간 추가" 상태를 활성화한 뒤 해당 일정의 시작 시간과 종료 시간을 자동으로 채워 넣고 확정합니다.
  - 사용자가 선택한 **날짜는 그대로 유지**되면서 **시간과 캘린더**만 정확하게 이전 일정에 맞춰 채워집니다.

## 수동 테스트 가이드

1. **확장 프로그램 새로고침**:
   - 크롬 브라우저에서 `chrome://extensions/`로 이동합니다.
   - **구글 캘린더 제목 자동완성 (G-Cal History)**의 새로고침 버튼(🔄)을 클릭합니다.
2. **구글 캘린더 열기**:
   - [Google Calendar](https://calendar.google.com/) 페이지를 새로고침(F5)합니다.
3. **시간 자동완성 테스트**:
   - 빈 시간대를 클릭하여 새 일정 모달창을 엽니다.
   - 제목 입력창에 기존에 등록했던 일정 제목의 앞글자를 입력합니다.
   - 추천 목록에 ⏰ 시간 또는 📅 종일 뱃지가 함께 표시되는지 확인합니다.
   - 추천 항목을 클릭했을 때, 제목, 위치, 설명, 캘린더와 함께 **시작 시간 / 종료 시간**(또는 종일 체크박스)이 자동으로 맞춰지는지 확인합니다.
4. **일정 등록 시 강제 새로고침 테스트**:
   - 일정을 하나 새로 저장합니다.
   - 저장 후 1.5초 뒤 백그라운드에서 최신 캘린더 데이터를 다시 페치합니다 (F12 콘솔에 `forceRefresh successfully completed after save` 로그 확인 가능).
   - 바로 새 일정 생성창을 열고 방금 등록한 일정의 제목을 입력했을 때, 추천 목록에 즉시 나타나는지 확인합니다.
