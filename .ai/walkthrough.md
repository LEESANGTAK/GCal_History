# 구글 캘린더 자동완성 (G-Cal History v2.6) 작업 완료 보고서

요청해주신 **"다일 일정(여러 날에 걸친 일정) 기간 복구"** 기능과 **"과거 일정 누락 방지(API 페이지네이션 및 검색 최적화)"**가 적용되었습니다.

---

## 🚀 추가 및 개선된 주요 기능 (v2.6)

### 1. 다일 일정(여러 날에 걸친 일정) 기간 자동 복구
- **문제점**: 기존에는 시작 시간과 종료 시간만 자동완성하고 날짜는 전혀 건드리지 않아, 3일이나 5일 동안 이어지는 일정을 선택해도 당일 하루짜리 일정으로만 잡히는 한계가 있었습니다.
- **해결 방식**:
  - 기존 일정의 `startTime`과 `endTime` 사이의 **총 기간(일수)**을 정밀하게 계산합니다.
  - 사용자가 현재 클릭하여 선택한 **새로운 시작 날짜**를 기준으로, 기존 일정의 일수만큼 더하여 **종료 날짜(`End date`)**를 자동으로 계산하고 구글 캘린더 입력창에 입력합니다.
    - 예: 5월 1일 ~ 5월 3일(3일간) 종일 일정 → 새로 11월 10일을 클릭하고 자동완성을 선택하면, 종료 날짜가 자동으로 **11월 12일**로 설정되어 **3일간의 일정**으로 완벽 복구됩니다.
    - 시간 지정 다일 일정(예: 1박 2일 워크샵)도 시작 시간, 종료 날짜, 종료 시간까지 한 번에 맞춰집니다.
  - 자동완성 추천 목록에 **`📅 3일간 (종일)`** 또는 **`⏰ 오전 10:00 ~ 오후 6:00 (3일간)`**처럼 기간이 직관적으로 표시됩니다.

### 2. 2025년 과거 일정 누락 방지 (API 페이지네이션 적용)
- **문제점**:
  1. 기존 API 요청 시 `maxResults=500`으로 500개까지만 가져오고 페이지네이션이 없어, 일정이 많은 캘린더의 경우 500개를 넘어가는 과거 일정이 잘려 누락되는 현상이 있었습니다.
  2. 조회 기간이 기본 12개월(1년)로 설정되어 있을 경우, 현재(2026년 11월) 기준 1년 전인 2025년 11월 이전(2025년 상반기 등) 일정은 가져오지 못했습니다.
- **해결 방식**:
  - `background.js`에 **`nextPageToken` 루프**를 도입하여 캘린더당 최대 2,500개까지 페이지를 넘겨가며 일정을 빠짐없이 수집하도록 개선했습니다.
  - 검색어 비교 시 `val.trim().toLowerCase()`를 적용하여 공백으로 인한 검색 실패를 방지했습니다.

## 🔍 수동 테스트 가이드

1. **확장 프로그램 새로고침**:
   - `chrome://extensions/`에서 새로고침(🔄) 아이콘을 클릭합니다.
2. **과거 일정 조회 기간 확인 (2025년 일정)**:
   - 확장 프로그램 팝업을 열고, "과거 일정 조회 기간"을 **"최근 2년"** 또는 **"최근 3년"**으로 설정합니다. (설정 즉시 새로고침이 수행되어 2025년 일정을 모두 긁어옵니다.)
3. **다일 일정 자동완성 테스트**:
   - 구글 캘린더를 새로고침(F5)합니다.
   - 달력의 특정 날짜를 클릭하여 일정 생성 모달을 엽니다.
   - 여러 날에 걸쳐 있던 일정(예: 3일간의 출장이나 연휴)의 제목을 입력합니다.
   - 추천 창에 `📅 N일간 (종일)` 라벨을 확인하고 클릭합니다.
   - 시작 날짜는 내가 클릭한 날로 유지되면서, **종료 날짜가 자동으로 N일 뒤로 연장**되어 며칠에 걸친 일정이 온전하게 복구되는지 확인합니다.
