# 구글 캘린더 일정 자동완성 (G-Cal History)

구글 캘린더에서 새 일정을 등록할 때, 과거에 등록했던 일정들의 **제목, 시간/기간(종일·다일 포함), 참석자, 장소, 설명, 소속 캘린더**를 기억해 원클릭으로 자동완성해주는 크롬 확장 프로그램입니다.

## ✨ 주요 기능
- **다중 캘린더 과거 일정 통합 검색** (최근 1개월 ~ 최대 3년 조회 기간 설정)
- **원클릭 전체 항목 자동완성**: 제목, 시간/기간, 참석자, 위치, 설명, 캘린더 카테고리 자동 선택 (항목별 ON/OFF 설정 지원)
- **8개 언어 다국어 지원**: 한국어(`ko`), 영어(`en`), 일본어(`ja`), 중국어 간체(`zh_CN`), 중국어 번체(`zh_TW`), 이탈리아어(`it`), 독일어(`de`), 프랑스어(`fr`)

## 📋 최근 업데이트 (v2.5)
- 한국어 확장 프로그램 명칭을 **"구글 캘린더 일정 자동완성 (G-Cal History)"**으로 변경
- 이탈리아어(`it`), 독일어(`de`), 프랑스어(`fr`) 다국어 추가 지원
- 다른 일정 재선택 시 기존 위치·설명·참석자·다일 날짜 자동 초기화 후 반영
- 시간 자동완성 1시간 밀림 현상 및 캘린더 자동 선택 버그 수정
- 자동완성 선택 즉시 달력 미리보기 칩에 전체 제목이 반영되도록 한글(IME) 및 포커스 동기화 개선
- 추천 목록 스크롤 탐색 시 드롭다운이 닫히는 현상 수정 및 백그라운드 OAuth 토큰 만료 처리 안정화
